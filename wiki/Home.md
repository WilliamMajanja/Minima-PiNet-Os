# Minima PiNet OS Wiki

Welcome to the **Minima PiNet OS** wiki — the comprehensive documentation hub for a decentralized, blockchain-native operating system built for Raspberry Pi 5.

---

## What is PiNet OS?

Minima PiNet OS is a **zero-bloat Linux distribution** designed for edge computing, decentralized applications, and AI inference on Raspberry Pi hardware. It integrates the Minima blockchain for identity, trust, and P2P communication, paired with a browser-based desktop environment for visual management.
